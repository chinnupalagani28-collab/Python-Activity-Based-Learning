# Python Activity-Based Learning — 10 Case Studies

This repository contains ten worked Python case studies selected from the supplied
`Python Activity1 case studies.pdf` assignment list.

## Selected problems

| Problem No. | Case study |
|---|---|
| 2 | Progressive Electricity Billing |
| 4 | Employee Payroll and Deduction Analysis |
| 7 | Retail Billing with Multiple Discount Rules |
| 12 | Attendance Recovery Computation |
| 13 | ATM Transaction Sequence Simulation |
| 14 | Warehouse Inventory Reconciliation |
| 17 | Student Performance Trend Analysis |
| 23 | Student Timetable Conflict Detection |
| 42 | Student Marks Matrix Analysis |
| 53 | Food Waste Monitoring System |

## Repository contents

- `Python_Activity_Based_Learning_10_Case_Studies.pdf` — detailed report with all ten required sections.
- `case_XX.py` — individual Python source files.
- `screenshots/` — sample terminal output screenshots and flowchart images.
- `outputs/` — reserved for additional run outputs if needed.

## Requirements

- Python 3.x
- No third-party Python packages are required to run the programs.

## Run a program

Open a terminal in this folder and run, for example:

```bash
python case_02.py
```

Repeat with the required case number.

## Upload to a new GitHub repository

1. Sign in to GitHub and create a new repository named `Python-Activity-Based-Learning`.
2. Keep the repository public or private as instructed by your faculty.
3. Upload the contents of this folder, or use Git:

```bash
git init
git add .
git commit -m "Add 10 Python activity-based learning case studies"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Python-Activity-Based-Learning.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. Do not upload passwords, tokens, or other private information.
